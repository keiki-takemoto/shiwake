# スタッフの声 仕分け台

店舗スタッフからLINEで届く連絡を貼り付けると、

- 改善点
- 購入品
- 共有事項
- 商品開発提案

の4つに仕分けて、タスク管理表にするWebアプリ（PWA）です。
携帯のホーム画面に置いて、アプリのように使えます。

## 使い方

1. LINEでトークをコピー
2. アプリで「貼り付け」→「仕分ける」
3. 結果を確認して「タスク表に追加」

提案日は、その日の日付（記帳日）が入ります。あとからまとめて入力するときは
「本文の日付を使う」に切り替えると、LINEの日付行を読み取ります。

## 仕分けのしかた

- 既定は**キーワードのルール**で仕分け。オフラインでも動きます。
- 設定でAnthropicのAPIキーを入れると、**Claudeが文脈を読んで**仕分けます。
  キーはその端末のブラウザの中だけに保存され、Anthropic以外には送りません。

## データの置き場所

タスクは**その端末の中だけ**に保存されます（サーバーには送りません）。
機種変更の前に、設定の「バックアップを保存」でJSONを書き出してください。
Excelに持っていくときは「CSVで書き出す」。

## 直すとき

- 画面と動きは `index.html` の1ファイルだけ。
- 直したら `sw.js` の `CACHE = "shiwake-v1"` の番号を1つ上げる（そうしないと古い画面が残ります）。
- アイコンは `python3 make_icons.py Z`（Z＝ZIPANGの頭文字。ほかにA〜Dの案、`sheet` で比較用の1枚）。
  お店のロゴを使うなら `sips -Z 512 logo.png --out icons/icon-512.png` のように作り直す。
- アイコンを変えたら、ホーム画面のアプリを一度削除して追加し直さないと、古い絵のままです。
- mainブランチに push すると GitHub Pages に反映されます（1分ほど）。
