# 仕分け台（作り直し中）

店舗スタッフからLINEで届く連絡を、改善点・購入品・共有事項・商品開発提案の
4つに仕分けてタスク表にするWebアプリ。

2026-09-19、仕分けの精度が実務に合わなかったため、いったんアプリを取り下げた。
公開URL（https://keiki-takemoto.github.io/shiwake/）とアイコンはそのまま残し、
作り直し中の案内ページを置いている。

- 前のアプリ一式は Git の履歴に残っている（`git log` の「アイコンの地を黒に変更」より前、
  取り下げ直前は `git show HEAD~1:index.html`）。必要なら取り戻せる。
- 案内ページには、端末に残っているタスクをCSVで取り出す機能を付けてある。
- アイコンは `python3 make_icons.py Z`（Z＝ZIPANGの頭文字）。
- 作り直したら `sw.js` を作り直し、mainに push すれば1分ほどで反映される。
